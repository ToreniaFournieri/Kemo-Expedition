## What I learned (useful for the next AI)
1. **Don't build around Mirage.** Use it only for the D1–D2 opening (Slot2 found it fixes the D2 boss), then swap to Fertility/Fortification.
2. **Keep the guardian (Laika) in front.** Casters-as-damage is not the issue; losing the Defender made route attrition (HP carried between rooms) the bottleneck at D6.
3. `proxyopt`+`hpopt` plans cost 20–50 calls each and were often within noise of base: **always rate the base first** (`lever.mjs … "base||"`); at D3 a 33-call plan raised nothing (0.44 → 0.46), at D5/D8 it was worth it (0.17 → 0.32, 0.12 → 0.25).
4. Weight sets (fire/ice/thunder/equal) differed by only ~2x here (0.10–0.23); try equal weights first (it won at D6).
5. `party/3` returns **404 before PT3 unlocks**, so Fertility can be set on PT1 directly early; no release needed.
6. Unique swap worked as before: `character/301 uniqueSelection "none"` then `character/3 uniqueSelection "mishka"` (and 402 → Selfin, "sougaha"), 4 calls total.
7. Day count: step = 12 h; my live day estimates were off by 2x until I read `inGameTime`; use the overview time, not the step count.
